        Программа "Учет результатов диспансеризации" предназначена для автоматизации обработки
    медицинских данных воспитанников детского сада. Она позволяет систематизировать информацию о
    состоянии здоровья детей по результатам осмотра четырех специалистов и формировать различные
    отчеты для администрации дошкольного учреждения.


    Функциональные возможности:

        Загрузка и хранение данных:
        Чтение информации из текстового файла формата CSV (значения разделены точкой с запятой)
        Хранение данных о каждом ребенке: ФИО, дата рождения, группа, результаты обследования 4 врачей

    Обработка данных:

        Проверка корректности формата входных данных
        Подсчет количества здоровых заключений для каждого ребенка
        Фильтрация детей по заданным критериям

    Формирование отчетов:

        Отчет 1: Полный список всех детей, отсортированный по количеству здоровых заключений (убывание) и фамилии (возрастание)

        Отчет 2: Список детей заданной группы, отсортированный по дате рождения (год, месяц, день)

        Отчет 3: Список детей, нуждающихся в лечении хотя бы у одного специалиста, отсортированный по группе и фамилии

    Алгоритмы сортировки:

        Реализован метод Хоара (быстрая сортировка) с различными режимами сортировки
        Поддержка многоуровневой сортировки по нескольким ключам

    Интерфейс пользователя:

        Консольное приложение с последовательным выводом отчетов
        Автоматическая загрузка данных из файла при запуске
        Четкое форматирование вывода с разделителями и заголовками
        Обработка ошибок при работе с файлами и некорректными данными

    Обработка ошибок:

        Проверка существования и доступности файла с данными
        Обработка пустых файлов и некорректных записей
        Формирование понятных сообщений об ошибках для пользователя

    Технические особенности:

        Модульная архитектура (разделение на логические модули)
        Использование рекурсивных алгоритмов сортировки
        Работа с кодировкой UTF-8 для поддержки кириллицы
        Минимальные требования к системным ресурсам
        Программа представляет собой законченное решение для автоматизации учета медицинских данных в дошкольных учреждениях, соответствующее требованиям задания по реализации алгоритмов сортировки и обработки структурированных данных.
